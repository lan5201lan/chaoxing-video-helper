============================================
  学习通刷课助手 - 使用说明（开箱即用版）
============================================

本程序用于自动播放学习通（超星）课程的视频任务点，
自动处理播放中的答题弹窗（单选/判断/多选），
看完一节自动切下一节，直到整章刷完。

【适用环境】
  - Windows 电脑（Win10 / Win11）
  - 需要安装一个"安卓模拟器"来运行学习通 App
    （推荐：雷电模拟器，或 MuMu 模拟器）

============================================
  第一步：安装安卓模拟器（只需一次）
============================================

1. 下载并安装模拟器（任选一个，推荐第一个）：

   · 雷电模拟器（推荐，最稳定）
     官网：https://www.ldmnq.com

   · MuMu 模拟器（网易）
     官网：https://mumu.163.com

2. 安装完成后，打开模拟器，把模拟器设置为【竖屏】：

   雷电模拟器：
     设置 → 显示 → 分辨率选择「手机版」，宽 1080、高 2400，
     并确保是竖屏方向。

   MuMu 模拟器：
     设置 → 显示 → 分辨率 1080×2400（竖屏）。

   ★ 如果找不到 1080×2400，任何"竖屏"分辨率都可以，
     程序会自动适配，但 1080×2400 最稳。

3. 关闭模拟器的"平板模式"，保持手机竖屏形态。

============================================
  第二步：安装学习通 App（只需一次）
============================================

在模拟器里：
1. 打开模拟器自带的应用商店，搜索「学习通」或「超星学习通」
2. 安装，并用你的账号登录
3. 进入你要刷的那门课，停在【章节】列表页（能看到 2.1.1、2.1.2 这类小节）

============================================
  第三步：启动刷课（每次刷课都这么做）
============================================

1. 确保模拟器已经打开，学习通停在【章节列表页】（竖屏）
2. 双击本文件夹里的「一键启动.bat」
3. 程序会自动：
     - 检测并连接模拟器
     - 识别屏幕上的章节
     - 点进章节 → 点播放 → 处理答题弹窗 → 播完 → 切下一节
     - 循环直到刷完

【停止方法】
  直接关闭弹出的黑色命令行窗口，或按 Ctrl + C。

============================================
  重要提示
============================================

1. 刷课期间【不要碰模拟器】，否则会干扰程序的点击操作。

2. 模拟器窗口保持打开，不要最小化到后台（部分模拟器
   最小化后会暂停画面，影响截图识别）。

3. 视频无法倍速（课程关闭了倍速），一节约 20-30 分钟，
   刷完整章需要数小时，请耐心等待，程序会全自动运行。

4. 进度会自动保存（progress.txt），中途关闭后再启动，
   会从上次的进度继续，不会重复刷已完成的章节。

5. 如果答题弹窗出现「多选题」，程序会自动穷举组合，
   试到答对为止，无需人工干预。

============================================
  常见问题
============================================

Q: 启动后提示"未检测到设备或模拟器"？
A: 说明模拟器没开，或程序没连上。请：
   1. 确认模拟器已完全启动（能看到安卓桌面）
   2. 关闭本程序，重新双击「一键启动.bat」

Q: 一直卡住不动？
A: 可能是弹窗卡住了，或模拟器画面暂停。
   按 Ctrl+C 停止，重新启动一次即可（进度已保存）。

Q: 换了电脑还能用吗？
A: 可以。把整个文件夹复制过去，装好模拟器 + 学习通，
   双击「一键启动.bat」即可，无需安装 Python 或任何环境。
