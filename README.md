# 学习通视频刷课助手

基于 **ADB + RapidOCR** 的自动化脚本，用于自动完成超星学习通的「视频任务点」：
自动进入章节 → 点击播放 → 处理中途弹出的答题弹窗 → 视频播完后退出 → 切换下一节，循环直到整章刷完。

> ⚠️ **免责声明**：本工具仅供自动化技术学习与研究使用。自动刷课可能违反学习通平台用户协议，
> 存在账号被限制的风险，请自行评估并承担一切后果。请勿用于任何违反校规、平台规则或法律法规的用途。

## 功能特性

- 自动在章节列表中定位「未完成」的视频章节
- 点击视频中央播放键开始播放
- 播放过程中实时识别并处理答题弹窗：
  - **单选 / 判断题**：点击选项后自动提交关闭
  - **多选题**：穷举选项组合，提交后根据弹窗是否重弹判断对错，直至答对
- 视频自然播完后自动返回章节列表，向下滚动寻找下一节
- 进度自动保存到 `progress.txt`，中途中断后可断点续刷

## 环境要求

- Windows 10 / 11
- Python 3.8+
- ADB（Android Debug Bridge）
- 运行学习通的安卓设备（真机 USB 调试，或安卓模拟器）

## 安装依赖

```bash
pip install rapidocr_onnxruntime opencv-python pillow numpy
```

> RapidOCR 基于 onnxruntime，无需 PyTorch。首次运行会自动下载中文识别模型（需联网）。

## 连接设备

### 方式一：安卓真机（USB 调试）

1. 手机开启开发者选项（设置 → 关于手机 → 连续点击「版本号」7 次）
2. 开启「USB 调试」，用数据线连接电脑
3. 手机弹窗点击「允许 USB 调试」
4. 验证连接：`adb devices`，看到设备且状态为 `device` 即成功

### 方式二：安卓模拟器

脚本会自动探测常见模拟器的 ADB 端口（雷电 5555、MuMu 7555、夜神 62001、逍遥 21503 等），
模拟器启动后无需手动连接。

## 运行

1. 在设备上打开学习通，进入目标课程的「章节」列表页（竖屏）
2. 运行脚本：

```bash
python main.py
```

或直接双击 `一键启动.bat`（Windows）。

按 `Ctrl+C` 可随时中断，进度已保存，下次会从断点继续。

## 配置

所有可调参数集中在 `config.py`：

| 配置项 | 说明 |
|---|---|
| `EMULATOR_PORTS` | 模拟器 ADB 端口列表 |
| `COMPLETED_KEYWORDS` | 判定视频播完的关键词 |
| `QUIZ_POPUP_KEYWORDS` | 答题弹窗识别关键词 |
| `BACK_ICON_*` / `PLAY_BUTTON_*` | 返回键 / 播放键坐标比例 |
| `POLL_INTERVAL` | 轮询间隔 |

## 文件说明

| 文件 | 作用 |
|---|---|
| `main.py` | 主流程状态机 |
| `adb_utils.py` | ADB / 截图 / OCR / 点击等底层工具 |
| `config.py` | 所有可调参数 |
| `一键启动.bat` | Windows 一键启动脚本 |
| `progress.txt` | 刷课进度记录（断点续刷） |

## 已知问题

- 视频倍速被课程关闭时无法加速，需等待自然播完（一节约 20~30 分钟）
- 部分模拟器最小化后会暂停画面，影响截图识别，请保持窗口打开
